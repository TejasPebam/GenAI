# Presentation / Viva Flow

## 1. Home

Introduce the problem: GitHub repositories can be difficult for beginners to
understand.

## 2. Explain Repository

Enter a public GitHub repository URL and click Explain Repository.

Explain that the backend validates the URL and obtains the repository's
default branch.

## 3. Repository Processing

Explain that GitPython is the primary cloning implementation. If system Git
is unavailable, a GitHub archive fallback keeps repository acquisition
working.

## 4. Code Processing

Explain that Python filters unnecessary folders and binary files and extracts
relevant source/configuration/documentation files.

## 5. Local GenAI

Explain that Ollama runs Qwen 2.5 3B locally. No cloud LLM API key is needed.

## 6. Repository Information

Show repository metadata such as branch, language, stars, forks and
description.

## 7. Code Structure

Show the files that were extracted for analysis.

## 8. File Viewer

Select a file and show the extracted content.

## 9. AI Explanation

Show the explanation generated by the local Qwen model.

## 10. Summary

Show the total files, source files, primary language and repository type.

## Key Point

The explanation is dynamically generated from the repository content by the
local LLM. It is not hard-coded.
