# Mini Project: Local GitHub Repository Code Explainer

A local GenAI application that accepts a GitHub repository URL and generates a simple-language explanation of the codebase.

## Architecture

GitHub Repository → GitPython → Source Code Extraction → Local LLM (Ollama) → FastAPI → Streamlit

## 1. Install Python packages

```bash
pip install -r requirements.txt
```

## 2. Install and prepare Ollama

Install Ollama on your computer, start the Ollama service, and pull a small model. The backend defaults to `qwen2.5:3b-instruct`, but you can change it with the `OLLAMA_MODEL` environment variable.

Example:

```bash
ollama pull qwen2.5:3b-instruct
```

## 3. Start the FastAPI backend

Open Terminal 1:

```bash
uvicorn backend:app --reload
```

Backend:
`http://127.0.0.1:8000`

## 4. Start the Streamlit frontend

Open Terminal 2:

```bash
streamlit run frontend.py
```

Streamlit will open in your browser.

## 5. Test

Paste a public GitHub repository URL, for example:

```text
https://github.com/username/repository
```

Then click **Explain this GitHub Repository**.

## Project requirements covered

1. Clone repository — GitPython
2. Identify source files — extension and folder filtering
3. Extract code — Python file handling
4. Send code to a local LLM — Ollama HTTP API
5. Generate explanation — prompt-based generation
6. Display explanation — Streamlit

## Notes

- The explanation is generated by the local LLM; there is no hard-coded project description.
- The backend excludes common large/generated folders such as `.git`, `node_modules`, virtual environments, build folders, and cache folders.
- Very large repositories are truncated to keep the LLM prompt manageable.
