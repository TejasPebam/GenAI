# Generative AI Assignment 08

This project demonstrates two Generative AI models:

* **DCGAN** using the Fashion-MNIST dataset to generate new images.
* **Autoencoder & VAE** using MNIST for image reconstruction and latent-space generation.

### Technologies

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib

### Key Concepts

* GAN Generator & Discriminator
* Image generation
* Autoencoder reconstruction
* VAE latent-space representation
* KL Divergence
* Latent-space image generation
